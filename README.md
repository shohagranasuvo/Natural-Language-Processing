# Natural Language Processing

A learning and experimentation archive covering natural-language processing concepts, notebooks, datasets, and course projects. It includes work with tokenization, stop-word processing, n-grams, similarity, BERT/RoBERTa, spam detection, and larger NLP project experiments.

## Repository layout

- `Learning Code/` — foundational experiments
- `BERT/`, `RoBERTa_NLP_Final_Term_Project/` — transformer-based work
- `Stop_word/`, `n_gram/`, `cosine_similarity/`, `Part_of_speech.ipynb` — core NLP exercises
- `Final term Project code Full/`, `nlp_mid_project_group_11/` — course project work
- `Spam detaction/` — classification experiments

## Getting started

Open the relevant notebook or project directory, review its imports and data paths, create an isolated Python environment, and install the dependencies used by that project. Because this is a multi-project learning archive, requirements can vary between folders.

## Status

Academic learning and research-experiment repository rather than one packaged application.
